# AI-Podcast-Engine 🎙️
### Turn Articles into Engaging Audio Conversations
**AI-Podcast-Engine** is a powerful Python-based tool designed to help content creators, students, and professionals repurpose long-form text into "listenable" content. Using the advanced Gemini 2.5 Flash API, it transforms static text into a dynamic, two-person dialogue script ready for professional Text-to-Speech (TTS) production.
## 🚀 Why This Project?
In an era of information overload, people prefer consuming content while commuting, exercising, or multitasking. This engine bridges the gap between reading and listening by:
 * **Humanizing Data:** No more boring summaries. Get a "Host" and an "Expert" discussing your topic.
 * **Tone Customization:** Switch between academic rigor, comedic banter, or heated debate.
 * **Audio-Ready Output:** Includes scene markers like [Short Pause] and [Music Intro] for seamless TTS integration.
## 🛠️ Features
 * **Dual-Persona Dialogue:** Natural interaction between a curious host and a deep-dive expert.
 * **Dynamic Tones:** Select from **Informative**, **Funny**, or **Debate** modes.
 * **Reliable Engine:** Built-in exponential backoff to ensure API stability.
 * **Clean Formatting:** Ready-to-use text files for inputting into tools like ElevenLabs or OpenAI TTS.
## 📖 User Guide
### 1. Installation
Clone the repository and install the dependencies:
```bash
git clone [https://github.com/hammadvirk-dev/AI-Podcast-Engine.git](https://github.com/hammadvirk-dev/AI-Podcast-Engine.git)
cd AI-Podcast-Engine
pip install -r requirements.txt

```
### 2. Usage
Run the main script:
```bash
python podcast_gen.py

```
 1. Paste your article or text when prompted.
 2. Select your desired tone.
 3. Your formatted script will be printed to the console and saved as generated_script.txt.
